# Workout Tracker
 
A console-based workout tracking application written in C++ that allows multiple users to create, manage, and track workout routines across multiple training days.
 
## Features
 
- Multiple user profiles
- Multi-day workout routines
- Exercise tracking
- Exercise name
- Muscle group
- Equipment
- Sets
- Repetitions
- Weight
- Edit existing workout routines
- Delete workout routines
- Persistent file-based storage
- Menu-driven interface
 
## Technologies
 
- C++
- Visual Studio
- Git
- GitHub
 
## Project Structure
 
src/ - Application source code
data/ - Sample workout data
images/ - Screenshots
docs/ - Additional documentation
 
## Example Workflow
 
1. Select an existing user or create a new one
2. Create workout days
3. Add exercises
4. Track sets, reps, and weight
5. View and modify routines
 
## Future Improvements
 
- Graphical user interface (GUI)
- Exercise search functionality
- Progress tracking and analytics
- Export workout data
- Password-protected user accounts
